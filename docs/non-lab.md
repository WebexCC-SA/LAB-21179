About this lab

This lab introduces creating intermediate to advanced flows in the Webex Connect CPaaS Platform. We will be creating 3 flows that showcase Rich Communiation Channel functionals including Rich Cards and Carousels. We will then complete create a new Autonomous AI Agent and then time permitting create one or two more bonus flows showing off the power of an LLM powered AI Agent.

You will learn how to:

* Create a new flow from scratch
* Create flows using the RCS Channel including Rich Cards and Carousels
* Create an Autonomous AI Agent from scratch with a RAG knowledge base
* Insert business logic
* Create a flow to interact with above AI Agent
